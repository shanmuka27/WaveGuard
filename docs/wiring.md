# Hardware wiring plan

The hardware owner will record final Arduino pin assignments here before assembly.

Required components:

- Arduino Uno
- HC-SR04 ultrasonic sensor or equivalent
- Green, yellow, and red LEDs with appropriate resistors
- Piezo buzzer
- Breadboard and jumper wires
- Water tray with a stable sensor mount

Mount the ultrasonic sensor vertically above the water. Record the empty/reference distance used by the backend conversion. Keep electronics isolated from splashes.
